# Simulate World

An essay on ecology, civic models, and collective decisions, with a companion reading list.

## Preview

Run `python3 -m http.server 8765` from this directory. Open http://localhost:8765/.
The main essay is at `/`; the reading list is at `/reading.html`. The alternate
contemporary draft is preserved at `/draft/`. `/about/` contains a brief author bio; `/news/` redirects to the reading list.

## Editing

`build.py` generates the essay and reading list from `source/thesis.json`,
`source/resources.json`, and `reading-data.json`. Run `python3 build.py` on macOS
(the generator uses `sips` to read image sizes). All required images are included.
Edit the generator rather than generated HTML. Layout uses `style.css`,
`edition.css`, and `edition.js`. Edit prose in `source/thesis.json`. Editorial decisions and audits are recorded in [`devlog/`](devlog/README.md); dating notes are in `EDITORIAL.md`.

## Hosting

This is a static site, with no Node server or installation step. GitHub Pages
can publish the repository root directly; `.nojekyll` bypasses Jekyll processing.
The `main` branch publishes to GitHub Pages. Earlier versions remain in Git
history. The public address is https://simulate.world/. Cloudflare proxies the
apex and www CNAME records to orbitalfoundation.github.io, redirects HTTP to
HTTPS, and redirects www to the apex while preserving paths and queries.

Search metadata is generated by build.py. robots.txt and sitemap.xml advertise
the essay, reading list, and About page. copy-edits.json contains narrow mechanical corrections;
approved factual revisions are incorporated in the source and documented in `devlog/`.

## Revision history

### September 18, 2026 — Cleanup together

Anselm Hook and OpenAI Codex worked together on a cleanup of the essay and site.
We kept the nine chapters, their emotional arc, and all 50 part images, while
modernizing typography, navigation, and mobile reading. A separate contemporary
riff is preserved at `/draft/`.

The cleanup included a source-linked correctness audit, corrections to names and
scientific claims, clearer distinctions between scenarios and predictions, and a
sourced California water table in place of the statistical notes. The reading
list gained book covers, the video presentation, linked Voices biographies and
selected portraits. Repeated bylines were reduced, and the author link now leads to a short About
page with Substack, Medium, and X links. At Anselm’s request, the 2016
book *The Origin and Nature of Life on Earth* was added to the reading list.

We also added search/social metadata and moved publication to GitHub Pages on
`main`, with Cloudflare routing for simulate.world. See the [audit and correction
record](devlog/README.md) for findings, sources, changes, and remaining limits.
